# SiteStamp 规格说明（SPEC）

中建国际乌兹公司 · 乌兹别克斯坦国家博物馆项目 · 现场水印相机
最近更新：2026-11-11（S0 规格对齐）

> **契约依据**：外部设计契约 `WatermarkCameraEngine 1.0.0` 已完整保存于
> [`docs/contracts/WATERMARK-CAMERA-ENGINE.yaml`](contracts/WATERMARK-CAMERA-ENGINE.yaml)。

## 1. 目标用户与场景

现场安管与分包安全员，在工地上抬手拍一张，照片自带合规水印，直接用于隐患整改、
检查记录、周例会材料。**不允许让他们在拍照时逐字打字**——字段值必须能一键选。

## 2. 拍摄

### 2.1 当前已实现（v1.10）✅

| 项 | 规格 |
|---|---|
| 画幅 | 4:3（竖拍出 3:4 竖图），取景区与成片比例一致，不裁剪不拉伸 |
| 取景 | 全屏沉浸，取景区只放画面 + 水印预览，**任何按钮都不压在画面上** |
| 快门 | 即时响应：按压缩放 + 白闪 + 震动 + 保存进度 + 结果胶囊；渲染在后台队列 |
| 闪光灯 / 镜头 | 顶栏切换，前摄无闪光单元时自动忽略 |
| 旋转 | 支持横竖屏自动切换，旋转后自动重建相机绑定，字段值不丢 |

### 2.2 当前 / 目标对照

| 项 | 当前（v1.10） | 目标（契约 1.0.0） | 状态 |
|---|---|---|---|
| 画幅 | 4:3 | 契约写 16:9，**本项目不采用** | ✅ 保持 4:3 |
| 方向 | 横竖屏自动切换 | 契约写 `portrait_fixed`，**本项目不采用** | ✅ 保持自动切换 |
| 双指缩放 `pinch_zoom` | 无 | 取景区支持双指缩放 | ⏳ 待实施 |
| 点击对焦 `tap_to_focus` | 无 | 点击画面位置对焦 | ⏳ 待实施 |

- **画幅保持 4:3**（已与用户确认，不采用契约的 16:9）：16:9 竖拍会出细长图，
  上下留白多，贴进报告或打印都不方便。
- **方向保持横竖屏自动切换**（不采用契约的 `portrait_fixed`）：现场横拍、竖拍都有，
  锁竖屏会限制取景。

## 3. 水印

### 3.1 位置与尺寸 ✅

- 位置：**固定左下角**，边距 画面宽/高 3.4% / 3.0%
- 尺寸：全部按卡片宽度（= 画面宽 68%）归一化，换画幅比例不变
- **明确不做**拖拽、不吸附四角（契约的 `draggable` / `haptic_snap_to_corners` 不实现）：
  现场形成肌肉记忆后位置乱跑会增加误操作；合规材料也要求水印位置固定。

### 3.2 样式

当前已实现 5 款（`WatermarkStyle.styleId`）✅：

| id | 名称 | 结构 |
|---|---|---|
| 1 | 三段式（当前默认） | 蓝标题条（左端 logo 白方块）+ 浅灰字段区 + 蓝落款条，圆角 2% 卡宽，带投影 |
| 2 | 深色卡 | 半透明圆角卡 + 左侧品牌色竖条 |
| 3 | 白卡 | 浅底圆角卡 + 顶部主色细条 + 主色大字时间 |
| 4 | 大时间条 | 底部通栏，时间超大，右侧显示首个字段值 |
| 5 | 角标 | 紧凑三行小卡 |

契约新增第 6 款「契约款」⏳：

| id | 名称 | 结构 |
|---|---|---|
| 6 | 契约款 ⏳ | 深色半透卡 `rgba(0, 0, 0, 0.55)`，圆角 8dp，padding 8/12/8/12，字体 system_sans，主文字 `#FFFFFF`，次文字 `#E0E0E0` |

- 「契约款」当前尚未实现；**落地后接替为默认样式**（当前默认仍为 1 三段式）。

- 默认配色（实测自现场样板）：品牌蓝 `#6190DB`、字段区 `#F4F5F7`、文字自动取深/浅
- 可调项（当前）：样式、底色（6 预设）、透明度 0–100%、主色（5 预设）、文字色（自动/白/深）、
  显示项（时间 / 天气 / 地址 / 经纬度）、logo、字段
- 标签与值**同字号同基线**，标签列定宽右对齐，两字标签用全角空格撑成四字宽
- 天气：Open-Meteo，10 分钟缓存，取不到则整行不显示，绝不阻塞拍摄

### 3.3 字段体系（目标）⏳

契约固定 7 个字段，分三段：

| 段 | 字段 id | 类型 | 默认值 / 选项 |
|---|---|---|---|
| 头部 | `f_logo` | IMAGE_ASSET | 品牌 logo 图片，最大高度 32dp |
| 头部 | `f_company` | STICKY_TEXT | 公司名，最多 30 字 |
| 头部 | `f_project` | STICKY_TEXT | 项目名 |
| 正文 | `f_matter` | ENUM_BADGE | 默认「质量验收」；选项：安全巡检 / 质量验收 / 工序交接 / 节前排查 / 物资进场 / 日常施工 |
| 正文 | `f_content` | INPUT_WITH_TAGS | 施工内容；快捷标签：基坑支护 / 梁板钢筋绑扎 / 混凝土浇筑 / 模板支撑体系 / 临电巡查 |
| 落款 | `f_location` | GEO_PROVIDER | `{address_line} ({lat_short}, {lng_short})` |
| 落款 | `f_weather_time` | AUTO_GENERATED（防篡改） | 时间 `YYYY-MM-DD HH:mm:ss`；天气 `{weather_condition} {temperature}°C {wind_direction}{wind_level}` |

- 该体系**取代现有的「用户自定义字段」**：现场人员不需要自造字段，固定 7 项反而一键即选、
  更快，也便于跨项目统一口径。
- 当前实现仍为「项目 → 模板 → 自定义字段」，固定字段体系尚未落地。

### 3.4 字段记忆（sticky）⏳

- 重开应用后复用上次选中值：`f_logo`、`f_company`、`f_project`、`f_matter`。
- 目标：零重复配置，开机即拍。
- 当前未实现。

### 3.5 logo 处理管线 ⏳

- 目标流程：自动去白底 → 边界裁剪 → 可选单色化。
- 当前实现：用户自选图片 → 采样 → 居中进 512 方图 → 存 `filesDir/logos/*.png`；
  上述管线尚未落地。

## 4. 数据

- 项目 → 模板 → 字段（三者都有 Room 表）；样式配置存在 `templates.styleConfig`（JSON）
- 相册**只存带水印成品**；渲染失败提示重拍，不落原图
- logo：用户自选图片 → 采样 → 居中进 512 方图 → 存 `filesDir/logos/*.png`

## 5. 界面分区

### 当前（v1.10）✅

```
① 顶栏：项目名 / 闪光 / 镜头
② 取景区 4:3
③ 底部：模板行 → 字段行 → [相册 | 快门 | 水印设置(Palette)]
```

水印设置入口统一为最底行的 Palette 图标。

### 目标（契约）⏳

```
① 顶栏 48dp：关闭 / 闪光 / 构图线网格 / 模板管理
② 取景区 4:3（保持，不采用 16:9）
③ 底部 120dp：[相册缩略图 | 快门 | 快速编辑（切换字段抽屉）]
```

- `btn_grid` 构图线开关 ⏳：当前只有固定的三分参考线，尚无开关按钮。
- `quick_edit_trigger` 快速编辑（切换字段抽屉）⏳：当前无此入口。
- 48dp / 120dp 为契约目标高度，当前未按此定尺寸。

其他待定项（未纳入契约）：扁平化、项目选择下移、最底行三个大项可自定义、
倒数第二行完全自定义。定稿后更新本节。
